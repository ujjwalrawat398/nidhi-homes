# Nidhi Homes Furniture — Website

Website for **Nidhi Homes Furniture**, Arsena, Agra (furniture manufacturer).

- Static site generated by `site/build.py` (Python 3, stdlib only) → `site/dist/`
- 92 pages: home, 8 category pages, 80 product pages, about, contact, 404
- Theme: Charcoal + Amber (locked 2026-11-21)
- WhatsApp enquiry: 8076273509
- Hosting: Netlify Free (deploy from this repo). Domain to be added later.

## Build locally

```bash
cd site && python3 build.py
```
